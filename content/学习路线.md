## 为什么是"AI 存储"

- **赛道在涨**：中国分布式存储市场 2022 年 104.2 亿 → 2025 年 289.4 亿元（CAGR≈40.6%）；全球 AI 存储约 $46.8B、CAGR 17.4%[1][4]
- **薪资差就是补课的价格**：备份研发岗 15-35K vs 存储底座岗 25-60K——"控制面 API 层"与"数据面内核层"的差价[2][3]
- **复合背景恰好是交叉点**：字节 AI 存储岗公开写明"纯 AI 侧或纯存储侧均可"[8]——你读研的 TensorRT/CUDA 资产让你"读得懂 AI 侧负载"，现职备份让你"摸得到存储侧"

> **为什么不选 AI 部署或 AI 图像？** AI 部署（AI Infra）看着光鲜，但你与它的"桥断了"——3 个月没碰 GPU、无大模型推理岗位履历，外投需从零重建；AI 图像（纯算法）你自评"肯定不够格"——论文/顶会门槛最陡。**AI 存储是唯一满足"懂 AI、用 AI"定位的方向**：不需要发明算法，需要的是读得懂 GPU 负载（KV Cache、训练 vs 推理 IO 模式），然后用存储技术解决它。你的读研部署资产在这里第一次被复用。

## 三条主线 · 28 个技术点

> 主线一（A）AI 存储 = 3-5 年差异化出口；主线二（B）分布式存储数据面 = 1-2 年主航道硬底子；主线三（C）RPC 体系补课 = 最大短板，最先补。每个技术点都配"是什么 / 为什么学 / 怎么学 / 可验证产出 / 岗位要求"。

## 操作式学习路径（Phase 0 – 4）

| Phase | 时间 | 做什么 | 里程碑 |
|---|---|---|---|
| **0 · RPC 补齐** | 0-1.5 月 | Thrift echo + gRPC echo 服务，抓包对比协议体 | 两个 demo 跑通推 GitHub |
| **1 · 迷你 Raft-KV** | 1.5-4 月 | Go 实现 Raft-KV：选举+日志复制+持久化 | 三节点集群选举/复制/宕机恢复 |
| **2 · Ceph 模块精读** | 4-9 月 | cephadm 起集群，精读 RADOS/BlueStore 写路径 | "一次 RBD 写"完整路径图 |
| **3 · KV Cache 实验** | 9-15 月 | vLLM 跑 7B 模型量化 KV Cache 显存；推演外置到 SSD 的 TTFT 预算 | 量化实验报告 |
| **4 · 开源 PR** | 12-24 月 | Longhorn（42 GFI）→ SGLang（49 GFI）/LMCache（最对口） | ≥1 个被合并 PR |

## 开源项目（新手推荐顺序）

1. **Longhorn**（[github.com/longhorn/longhorn](https://github.com/longhorn/longhorn)）— 42 个 good first issue、Go/CRD 生态，第一个 PR 首选
2. **SGLang**（[github.com/sgl-project/sglang](https://github.com/sgl-project/sglang)）— 49 个 GFI、Python 为主，站 AI 推理风口
3. **LMCache**（[github.com/LMCache/LMCache](https://github.com/LMCache/LMCache)）— 增长最快、与 AI 存储方向最吻合，pip 即跑
4. 进阶：vLLM → DeepSeek 3FS → Mooncake → Ceph / TensorRT-LLM

## 每周打卡

```
每周（≥6 小时）：
[ ] 读论文/文档 ×1（Raft → Ceph → PagedAttention → TraCT）
[ ] 写代码 ×1（echo → Raft-KV → fio 脚本 → KV 实验 → PR）
[ ] 跑实验/命令 ×1（thrift/grpc → cephadm → minio → vllm）
[ ] 写笔记 ×1（"存储方向"分类，累计：阶段一≥15 / 阶段二≥35 / 阶段三≥60）
[ ] 社区互动 ×1（读 issue、给 PR 评论）
```

## 三条纪律

1. **先补最短的板，不要先啃最酷的方向**——短板排序：RPC > 分布式底子 > AI 存储前沿；Phase 0 的 Thrift/gRPC echo 看起来"不够 AI"，但它是把"写接口"从黑盒里拽出来的第一步。
2. **每个技术点都要有可验证产出**——能跑、能测、能写进 GitHub 的动作才算完成。
3. **不要现在跳槽，但要现在攒履历**——开源 PR、量化实验报告、60 条存储方向笔记，是 18-24 个月后内部转岗或外部面试时"被看见的资本"。
