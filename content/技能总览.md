# 技能总览

> 本页基于研究生阶段学习与实践记录整理，按技能域分类，并标注掌握程度。
> 掌握程度分级：**实战项目级** = 有完整项目落地与量化结果；**动手实践级** = 写过代码 / 跑通完整流程；**概念了解级** = 理论储备 / 教程学习。

## 一、图像处理与融合算法

| 技能 | 掌握程度 | 关键证据 |
|---|---|---|
| 偏振成像链路（四方向 RAW → Stokes s0/s1/s2 → DOP） | 实战项目级 | 偏振相机数据处理全流程 |
| BM3D 去噪 CUDA 改造与自适应策略 | 实战项目级 | 方差自适应阈值 + 相似块数插值，warp 并行 + 共享内存 + SSIM 消融 |
| PDBFnet 双分支特征融合网络 | 实战项目级 | MG 提升 29.5%、SD 提升 163% |
| 弱光图像增强（U-Net + Transformer 色彩校正） | 实战项目级 | 检测召回率提升 17% |
| FusionGAN 红外-可见光融合 | 动手实践级 | 熵 12.513、平均梯度 39.560，参数 135.8 万 → 92.6 万 |
| 自适应权重融合 / 稀疏字典融合 | 动手实践级 | 熵权重、Sobel 梯度权重；K-SVD / OMP 稀疏表示 |
| 融合图像定量评价指标体系 | 动手实践级 | PSNR / SSIM / 信息熵 / 平均梯度手写实现 |
