### 项目一：OceanProtect 备份产品 Agent 插件后端开发

**时间**：2026.07 – 2026.09　|　**角色**：后端开发工程师　|　**领域**：存储与云平台

**背景（Situation）**

OceanProtect 是企业级备份产品，需支持 HCS（华为云栈）VHA（虚拟机高可用双活）场景下的虚拟机备份。VHA 双活虚拟机跨主/容两端运行，资源模型与普通虚拟机不同，原有备份链路无法直接适配，存在资源解析错误、快照不一致、增量备份断链等技术风险。

**任务（Task）**

负责 VHA 双活备份特性在 Agent 插件后端的落地，完成特性设计、编码改造、容错优化与全场景验证，确保与存量普通 VM 备份业务兼容。

**行动（Action）**

- **备份链路改造**：实现 VM 到 LUN（逻辑单元号）资源自动转换，识别主/容端实例，打通 VHA 虚拟机全量、增量备份完整流程；
- **快照管理重构**：重构快照生命周期管理逻辑，增加失败自动回滚机制防止脏快照残留；优化增量快照链维护，处理任务失败导致的断链异常；
- **状态机兼容设计**：改造备份状态机与任务分支，兼容普通 VM 与 VHA 双活 VM 两套路径，保障存量业务零侵入兼容；
- **容错与边界处理**：优化 IAM（身份与访问管理）鉴权与 API 调用容错，处理 DNS 解析、证书校验、网络抖动等边界问题；
- **质量保障**：覆盖各类故障异常场景，输出全套测试用例，完成插件编译部署验证；沉淀业务与排障文档，提升团队新人上手效率。

**结果（Result）**

- VHA 双活虚拟机备份特性完整落地，全量/增量备份流程跑通；
- 快照失败自动回滚与增量链维护机制上线，消除脏快照残留风险；
- 双路径状态机兼容存量业务，无回归问题；
- 全套测试用例与排障文档沉淀，覆盖故障异常场景。

### 项目二：多源图像智能分析与 AI 软件系统研发

**时间**：2024.06 – 2024.12　|　**角色**：算法与部署主导　|　**领域**：计算机视觉 / 深度学习 / 高性能部署

**背景（Situation）**

面向施工场景的多源（红外/可见光/偏振）图像智能分析需求，弱光环境下图像质量差、多模态数据难以对齐、嵌入式平台算力有限，需要从算法创新到嵌入式部署的端到端解决方案，实现实时应用。

**任务（Task）**

主导多源图像智能分析与 AI 软件系统研发，聚焦弱光增强、多模态协同处理与高性能部署，完成从算法设计、模型训练、轻量化压缩到嵌入式部署、可视化软件的全链路落地。

**行动（Action）**

- **双分支融合网络**：设计 PDBFnet 双分支特征融合网络，针对偏振图像清晰度提升问题，融合多尺度特征；
- **弱光增强流程**：结合 U-Net 弱光增强与 Transformer 颜色修正，优化低光照条件下的图像增强流程；

- **跨模态融合**：完成红外-可见光-偏振跨模态高精度对齐与融合，自研 FusionGAN 提升跨模态一致性与复杂场景鲁棒性；

- 跨模态对齐融合误差 **< 2px**；
- TensorRT 推理延迟优化至 **220ms**，实现实时应用；

- 多相机（可见光/红外/偏振）联合标定误差 **< 0.2px**；

### 项目三：基于 U-Net 的四边形关键点检测模型

**时间**：2025.08 – 2025.09　|　**角色**：算法设计与实现　|　**领域**：计算机视觉 / 相机标定

**背景（Situation）**

相机-投影仪标定系统中，标定光卡的四边形关键点检测是标定精度的关键环节。复杂背景、极端光照（过曝/欠曝）、部分遮挡等场景下，传统图像处理方法鲁棒性不足，需要深度学习方法提升检测准确性与稳定性。

**任务（Task）**

设计并实现基于 U-Net 的四边形关键点检测模型，结合图像预处理与几何约束机制，提升标定光卡在复杂场景下的识别准确性与稳定性。

**行动（Action）**

- **预处理管线**：提出基于 Gamma 校正、Otsu 二值化和形态学开闭运算的预处理管线，增强不同光照条件下边缘特征的稳定性；
- **四边形提取机制**：设计四边形提取与判定机制，结合凸性约束、面积约束和平行度一致性，有效筛选真实四边形、排除伪四边形；
- **遮挡角点恢复**：提出边缘反向延长线交点推断法，恢复被遮挡的角点；通过向量一致性判定排除杂散点干扰；
- **模型训练与鲁棒性增强**：实现基于 U-Net 的四边形关键点检测模型，结合自制大规模数据集训练，引入 FGSM（快速梯度符号法）对抗训练提高模型在动态场景中的鲁棒性与抗扰动能力。

**结果（Result）**

- 四边形关键点检测在复杂背景和极端场景（遮挡、过曝）下的识别准确性与稳定性显著提升；
- 预处理管线 + 几何约束 + 对抗训练的组合方案，为相机-投影仪标定系统提供了可靠的光卡检测能力；
- 相关相机标定能力旁证：多相机联合标定误差 < 0.2px，红外相机重投影误差 0.22px。
